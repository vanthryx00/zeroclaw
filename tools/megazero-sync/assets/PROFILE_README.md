## About MegaZero

MegaZero is a trait-driven, modular agent runtime: providers, channels,
tools, memory, observability, runtime adapters, peripherals, and sandboxes
are all swappable extension points. It runs on constrained hardware
(sub-5MB RAM targets) and stays secure-by-default.
